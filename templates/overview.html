Training Pipeline
How OsteoScan AI was built
Data Collection
12,000+ X-ray images across fracture and non-fracture classes sourced from two curated Roboflow datasets.
CLAHE Preprocessing
Contrast Limited Adaptive Histogram Equalisation applied to each image for consistent edge visibility across varying X-ray exposures.
YOLOv8m Training
100 epochs on dual T4 GPU with AdamW optimiser, cosine LR decay, and X-ray-specific augmentation (no hue/saturation shifts).
Fracture Type Classifier
Separate YOLOv8s model trained on Dataset 2 (13 fracture types) alongside visual morphology fallback using OpenCV.
Multi-API Body Part Detection
4-stage cascade: general body-parts API → upper-limb API → visual bone-shape analysis → positional fallback.
